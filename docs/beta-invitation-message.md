## Longer Version

Hi, I am looking for a few people to try an early Windows desktop app I am building: Task Calendar.

The idea is simple: it is not another heavy project-management tool. It is a local-first desktop command center for today's work. You can see today's status, overdue tasks, a short Today Action List, and an End-of-Day Review. It also shows where your data is stored and lets you export/restore JSON backups.

This is best for people who:

- Manage personal or solo work from a Windows desktop.
- Want a daily task view without a team workspace.
- Prefer no account and no cloud requirement.
- Care about local data and backup/restore control.

Please try it for about 3 days. I am especially interested in:

- Did it help you know what to do first today?
- Was Today Action List useful?
- Was End-of-Day Review useful?
- Did local-first/no-account feel valuable?
- What confused you?
- What would stop you from using it daily?
- Would you pay for a stable local desktop tool like this?
