## V2EX-Style Post

Title:

```text
I made a local-first Windows task calendar beta. Looking for a few testers.
```

Body:

```text
Hi everyone, I am building Task Calendar, a local-first desktop command center for today's work.

It is not trying to replace Jira, Notion, or team collaboration tools. The idea is smaller:

- open the app and know what to do first today
- see overdue and today tasks in one action list
- review what is done and what remains at the end of the day
- keep data local under %APPDATA%\Task Calendar\
- export/restore JSON backups manually

Current state:

- Windows portable ZIP beta
- unsigned app, so Windows may show a warning
- no account
- no cloud sync
- no reminders
- no installer yet

I am looking for 5-10 people who manage daily tasks on Windows and are willing to try it for 3 days.

Download: [download link]
Feedback: https://wj.qq.com/s2/26709573/338b/
Screenshots: [screenshot link]

I am especially interested in:

- whether Today Action List helps you decide what to do first
- whether End-of-Day Review is useful
- whether local-first/no-account feels valuable
- what would stop you from using it daily

This is a beta/local prototype, not a production-ready product.
```

## Posting Rules

- Post once per community unless there is a meaningful update.
- Be clear that it is beta.
- Mention limitations before people download.
- Ask for specific feedback, not praise.
- Respect community rules.
- Do not send bulk DMs.
