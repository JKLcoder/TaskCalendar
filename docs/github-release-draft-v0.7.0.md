# GitHub Release Draft: v0.7.0

## Release Title

Task Calendar v0.7.0 - Commercial Validation / Beta Distribution

## Short Description

Task Calendar v0.7.0 prepares the local-first Today-first desktop app for external beta testing. This release focuses on positioning, beta distribution materials, feedback collection, and commercial validation documentation.

This is still a beta/local prototype. It is not production-ready, not signed, and not commercially available.

## Who Should Try It

Try this beta if you:

- Manage daily work from a Windows desktop.
- Want a local-first task calendar.
- Prefer no account and no cloud requirement.
- Want to test Today Command Center, Today Action List, End-of-Day Review, and Data & Settings.
- Are comfortable trying an unsigned beta/local prototype.

## Download Instructions

Download the portable ZIP from the release assets:

```text
Task Calendar-0.7.0-portable-x64.zip
```

Then:

1. Extract the ZIP to a normal folder.
2. Run `TaskCalendar.exe`.
3. Do not run directly from inside the ZIP or from a temporary folder.

## Data Location

Task data is stored in the Electron user profile, not inside the portable folder.

On Windows packaged builds:

```text
%APPDATA%\Task Calendar\
```

Use `File > Data & Settings...` to view the data path, open the data location, export a JSON backup, or restore valid schema v1 JSON.

## Known Limitations

- Unsigned Windows app.
- Placeholder icon.
- No installer.
- No cloud sync.
- No account system.
- No payment or subscription.
- No license server.
- No tray integration.
- No reminders or notifications.
- Portable ZIP data does not travel with the extracted app folder.
