# Feedback Guide

Use these questions with beta testers. The goal is to learn whether Task Calendar is useful enough to become a stable local desktop product, not to collect generic praise.

## Current Workflow

- What do you currently use to manage daily tasks?
- Do you use a calendar, todo list, notes app, spreadsheet, paper, or something else?
- What happens when a task is not finished today?
- Do you trust your current task system?

## Today-First Value

- Did Task Calendar help you know what to do first today?
- Was Today Command Center useful?
- Was Week Pressure useful?
- Was Today Action List useful?
- Did End-of-Day Review help you understand how the day ended?

## Local-First Value

- Did local-first/no-account feel valuable?
- Did knowing the data location matter to you?
- Did Export backup and Restore from JSON make the app feel safer?
- Was the portable data behavior clear?

## Confusion And Friction

- What confused you?
- What felt redundant?
- What felt too dense?
- What would stop you from using it daily?
- Did any wording or button label feel unclear?
- Did you understand where your data was stored?

## Willingness To Pay

- Would you pay for a stable local desktop tool like this?
- What one-time price would feel acceptable?
- Would `$19` feel reasonable?
- Would `$29` feel reasonable?
- Would `$39` feel reasonable for a lifetime local license?
- What feature or trust signal would need to exist before you paid?

## Final Product Fit Question

If Task Calendar disappeared tomorrow, would you miss it?

If yes, what exactly would you miss?
