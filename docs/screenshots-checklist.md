# Screenshots Checklist

Use this checklist to prepare screenshots for beta users, product pages, and commercial validation. Do not imply production readiness in captions.

## Core Product Screens

- Main calendar workspace.
- Today Command Center.
- Week Pressure signal.
- Today Action List.
- End-of-Day Review.
- Selected Day Details.

## Data Trust Screens

- File > Data & Settings menu entry.
- Data & Settings modal.
- Data location field.
- Current tasks count.
- Open data location result.
- Export backup native save dialog.
- Restore from JSON native open dialog.
- Restore replacement confirmation.

## First-Run And Setup Screens

- First-run Start blank / Use demo data / Import tasks.
- Portable ZIP in download folder, if useful.
- Extracted portable folder with `TaskCalendar.exe`, if useful.
- Windows trust warning, if documenting unsigned beta expectations.

## Suggested Captions

- "Open the app and see today's work first."
- "Action List shows overdue and today unfinished tasks."
- "Wrap today with a compact end-of-day review."
- "Data stays local and can be backed up as JSON."
- "Portable build runs without an installer, but data stays in the Electron profile."

## Screenshot Quality Notes

- Use a normal desktop window size.
- Avoid showing personal or sensitive task text.
- Use demo data or sanitized sample tasks.
- Keep the window title visible.
- Capture the whole right panel when showing Today-first workflow.
- Capture Data & Settings with the data path visible.
