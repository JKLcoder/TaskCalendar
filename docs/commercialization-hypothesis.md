# Commercialization Hypothesis

Task Calendar is not commercially available yet. This document defines what to validate before building payment, accounts, subscriptions, or licensing infrastructure.

## Product Hypothesis

Some users want a private, local-first desktop command center for daily work rather than another account-based cloud task app.

## Target User Hypotheses

- Solo professionals want a desktop-first daily command center.
- Local-first users prefer no account and no cloud requirement.
- Productivity tool users want less project-management overhead than Jira, Notion, or team collaboration tools.
- Users who handle sensitive or personal work value knowing where task data is stored.

## Pain Hypotheses

- Users start the day without knowing what to do first.
- Overdue tasks are easy to lose across scattered tools.
- End-of-day work is rarely closed cleanly.
- Cloud task tools feel too heavy for personal daily execution.
- Users worry that local prototype data may be mysterious or hard to back up.

## Willingness-To-Pay Hypotheses

- Users may pay for a stable local desktop tool if it reliably clarifies today's work.
- Local-first, no-account, user-controlled backup/restore may be a real differentiator.
- One-time pricing may fit the product better than subscription pricing at this stage.
- A signed installer and polished icon may be required before some users pay.

## Possible Pricing Experiments

- Free beta for early feedback.
- Personal license: `$19-$29`.
- Lifetime local license: `$39`.

These are test hypotheses, not final pricing.

## Validation Criteria

Before building payment or licensing:

- 5-10 beta users try the app.
- At least 3 users use it for several days.
- At least 2 users express real willingness to pay.
- At least 1 user asks how to get future updates.
- Users can explain the value in their own words without being prompted.

## What Not To Build Yet

- Payment.
- Subscription.
- Account system.
- License server.
- Cloud sync.
- Team collaboration.
- Multi-workspace system.
- Automatic backup service.
- Complex settings system.

## Next Commercial Readiness Signals

- Clear product positioning page.
- Screenshot set that shows the Today-first workflow.
- Stable portable ZIP download instructions.
- Feedback collection link.
- Manual beta outreach list.
- Repeated user demand for signed builds or paid stability.
